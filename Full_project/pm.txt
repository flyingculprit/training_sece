============================================================
BANK MANAGEMENT SYSTEM
POSTMAN API TESTING
===================

BASE URL:
http://localhost:8080

IMPORTANT:

1. Start the Spring Boot application.
2. Open Postman.
3. Test the APIs in the order given below.
4. For JSON requests:
   Body → raw → JSON
5. For Deposit/Withdraw:
   Params → Query Parameter
6. Check the expected status and response after every request.

============================================================

1. CUSTOMER SIGN UP
   ============================================================

Operation:
Create a new customer account

Method:
POST

URL:
http://localhost:8080/api/account/signup

Body:
Body → raw → JSON

Request JSON:

{
"accountNumber": 103,
"holderName": "Deepak Raj",
"password": "securePass123",
"balance": 5000.0
}

Expected Status:
200 OK

Expected Response:

{
"accountNumber": 103,
"holderName": "Deepak Raj",
"password": "securePass123",
"balance": 5000.0
}

============================================================
2. TEST DUPLICATE ACCOUNT NUMBER
================================

Purpose:
Check whether the system prevents duplicate account numbers.

Method:
POST

URL:
http://localhost:8080/api/account/signup

Body:
Same JSON as Step 1

Expected Status:
409 Conflict

Expected Response:

"Account #103 already exists. Please choose a different number."

============================================================
3. CUSTOMER SIGN IN (LOGIN)
===========================

Method:
POST

URL:
http://localhost:8080/api/account/login

Content-Type: application/json

Body:
Body → raw → JSON

"password": "securePass123"
